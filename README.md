# CMSC128-CRUDToDoList
Repository for a todo list highlighting the features of CRUD in a to do list reminder

Why Javascript only?
- A simple app such as a todo list with the given freedom of writing to local storage
is perfect for a solo javascript implementation because it has its own data format, JSON.
Not only that, but it has plenty of libraries that provide easy ways to write, store data,
and present data.
- Another reason for javascript only is that its universal, you won't need a cloud
storage db or a python environment or sdk's, you just need a browser.
